
# FastFilter — Learn Smarter

**Less noise. More learning.**

FastFilter is a browser-based study tool that helps students turn long lessons into focused revision materials. It extracts frequently used keywords, identifies important sentences, and creates practice prompts from pasted lesson text.

## Problem

Students often struggle to review long lessons efficiently. FastFilter provides a simple workspace to help them identify key terms and organize material for revision.

## Features

- **Filter Key Notes:** Identify frequently occurring keywords and highlight potentially important sentences.
- **Find Keywords:** Extract and rank frequently occurring words.
- **Practice Quiz:** Create practice prompts from lesson sentences.
- **Copy Results:** Copy generated study materials.
- **Download Notes:** Save results as a text file.
- **Browser-Based Processing:** The current prototype processes lesson text locally in the browser.

## How It Works

1. Paste a lesson into the text area.
2. Select a study tool.
3. Review the generated output.
4. Copy or download your study materials.

## Technology Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages for hosting

## AI Integration

The current version uses JavaScript-based text processing and does not yet integrate a generative AI model or external AI API.

A future version may integrate an AI model to provide clearer explanations, better summaries, and more meaningful practice questions.

## Getting Started

### Run Locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Paste a lesson and try the available tools.

No installation or API key is required for the current prototype.

## Deployment

The website can be hosted using GitHub Pages.

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Choose the `main` branch and the root folder.
4. Save and open the published website URL.

## Limitations

- Keywords are ranked by frequency, not by verified educational importance.
- Revision notes select existing sentences rather than generating a true summary.
- Practice prompts are template-based, not AI-generated.
- Users should review all results for accuracy.
